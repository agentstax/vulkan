---
title: "cron job request was already published by an earlier ambiguous commit"
slug: errors/VK0037
kind: "event"
level: "warn"
consequence: "degraded but self-healing, or a durable data consequence; an operator should learn of it eventually"
---

A scheduler tick found its job request already in the topic: an earlier
tick's commit confirmation was lost after the publish landed, so this
tick republished nothing. The idempotency key made the retry safe; the
job does not run twice.

---
title: "schedule message was already produced by an earlier ambiguous commit"
slug: errors/VK0037
kind: "event"
level: "warn"
consequence: "degraded but self-healing, or a durable data consequence; an operator should learn of it eventually"
---

A schedule producer tick found its message already in the topic: an earlier
tick's commit confirmation was lost after the produce landed, so this
tick produced nothing. The idempotency key made the retry safe; the
schedule's message does not land twice.

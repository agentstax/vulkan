---
title: "stored message options outside this consumer's bounds"
slug: errors/VK0032
kind: "event"
level: "warn"
consequence: "degraded but self-healing, or a durable data consequence; an operator should learn of it eventually"
---

A stored message requested options outside this consumer's
`MessageMin`/`MessageMax` bounds; the resolved options were clamped to
the bounds. The `stored` and `clamped` attributes carry both documents. Raise
the bounds if messages legitimately need more.

---
title: "worker instance lost"
slug: errors/VK0034
---

**Code** `VK0034` · **Log event** at warn -- degraded but self-healing, or a durable data consequence; an operator should learn of it eventually.

This instance's `worker_instance` row expired or was claimed by a
replacement while it was still running, so it stops and lets the
replacement run alone. Expect it after pauses longer than the instance
TTL -- GC, machine sleep, a network partition.

Messages resolved without running because a newer version of their
compacted message key had already arrived.

A session flow: this instance's own running total, flushed to
`__system.metrics` each flush tick and printed as `superseded_count` on
the [consumer stopped](/errors/VK0041) line. It never reconciles against
the fleet-wide `vulkan.consumer.*` gauges.

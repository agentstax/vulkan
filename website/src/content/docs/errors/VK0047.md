**Code** `VK0047` · **Metric** -- counter of `{message}`, one series per consumer session.

Delivery rows this instance wrote `'dead'`: exhausted retries,
unrecoverable payloads, and the crash-loop kill backstop. These sit in
the DLQ until resolved.

A session flow: this instance's own running total, flushed to
`__system.metrics` each flush tick and printed as `dead_count` on the
[consumer stopped](/errors/VK0041) line. It never reconciles against the
fleet-wide `vulkan.consumer.*` gauges.

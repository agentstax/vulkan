---
title: "vulkan.worker.state.unclaimed_workers"
slug: errors/VK0067
kind: "metric"
consequence: "gauge of `{worker}`, one series system-wide"
---

Workers with a nonzero instance target and no live instance.

The metrics collector counts the worker rows currently in that state. Zero
means every worker that should be running has a live instance. A positive value
means some maintenance work has no process claiming it.

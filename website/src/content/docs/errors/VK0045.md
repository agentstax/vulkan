Delivery rows written `'ready'`: each will be retried once its backoff
passes. A nonzero value is retry traffic, not lost work.

A session flow: this instance's own running total, flushed to
`__system.metrics` each flush tick and printed as `ready_count` on the
[consumer stopped](/errors/VK0041) line. It never reconciles against the
fleet-wide `vulkan.consumer.*` gauges.

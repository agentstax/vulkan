consumerFunc goroutines written off after the hard timeout; each left a
goroutine running unreachably until it returned on its own. How to keep
the count at zero: [Consumer Timeouts](/guides/consumer-timeouts/).

A session flow: this instance's own running total, flushed to
`__system.metrics` each flush tick and printed as `abandoned_count` on
the [consumer stopped](/errors/VK0041) line. It never reconciles against
the fleet-wide `vulkan.consumer.*` gauges.

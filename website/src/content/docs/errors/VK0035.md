---
title: "manager row suspended"
slug: errors/VK0035
kind: "event"
level: "warn"
consequence: "degraded but self-healing, or a durable data consequence; an operator should learn of it eventually"
---

The manager's own row has `target_instances` 0, so its worker chain goes
unreconciled until it is restored. Suspension is an operator action;
restore `target_instances` to resume.

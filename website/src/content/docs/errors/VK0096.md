---
title: "worker_liveness"
slug: errors/VK0096
kind: "alert"
consequence: "warn, owned by a topic; resolves once every worker row has a live instance"
---

A topic's worker rows have no live instance, so nothing runs its upkeep.

A worker row with no live instance does no work: expired partitions are not
dropped, exceptions are not retried, and the group's cursor stops
advancing. The hourly check lists each topic's worker rows with a nonzero
instance target and no instance, and publishes an active alert naming them.
The alert's `data` carries `unclaimed_count` and a `workers` list with each
row's `worker`, `owner`, `owner_kind`, and `target_instances`.

Only a process running the manager claims these rows: `vulkan manager run`
in a process that stays up, or any `Consume` on the topic. A produce-only
deployment sees this alert on every topic it produces to, because nothing
in that process runs upkeep.

```
vulkan alert list
```

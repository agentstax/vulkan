---
title: "vulkan.worker.state.failing_workers"
slug: errors/VK0069
kind: "metric"
consequence: "gauge of `{worker}`, one series system-wide"
---

Workers whose live instance has a nonzero consecutive failure count.

The count falls when an instance completes a successful run and its failure
streak clears. An unclaimed worker belongs to
[`vulkan.worker.state.unclaimed_workers`](/errors/VK0067), not this gauge.
